Both assets were generated with the built-in image generation tool, using the
user-provided three-screen prototype screenshot as a visual reference.
They are newly generated interpretations, not original Figma exports.
The selected outputs were inspected and copied into the project without edits.

Saved path: `frontend/public/images/brainring.png` (transparent PNG).

Thick dark navy outlines, fun hand-drawn sticker illustration, subtle dimensional shading, crisp readable silhouette. Composition square, tight generous safe margins, centered. Transparent background. No other text, no screen mockup. Asset intended for a Vue alarm clock app.
